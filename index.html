이용 안내 · 개인정보 · 출처
  • 이 사이트는 YouTube API 서비스를 사용해 채널 프로필·구독자 수·조회수·최신 영상 정보를 가져옵니다. 이 사이트를 이용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. 구글의 개인정보 처리 방식은 Google 개인정보처리방침을 따릅니다.
  • 채널 정보는 운영자의 자동 갱신 작업이 20분~4시간마다 YouTube에서 받아 저장소에 저장한 것을 보여줍니다(30일 이내 갱신). 이 사이트는 서버가 없고 회원가입·쿠키·방문 기록 수집을 하지 않습니다. 즐겨찾기, 정렬 설정, 직접 추가한 계정은 내 브라우저 안(localStorage)에만 저장되며 운영자에게 전송되지 않습니다. 브라우저의 사이트 데이터를 지우거나 아래 "기본 목록으로 되돌리기"를 누르면 삭제됩니다.
  • YouTube에서 받아온 데이터는 가공 없이 표시하며 60분 뒤 새로 받아옵니다. 프로필·썸네일을 누르면 YouTube의 해당 채널·영상으로 이동합니다.
  • 채널 설명과 "조사치" 숫자, 세부 분류는 언론 기사·공개 랭킹 사이트를 바탕으로 운영자가 정리한 것으로, 시점에 따라 실제와 다를 수 있습니다. 시사·정치의 성향 분류(진보·보수·언론)는 보도와 채널 자기소개를 기준으로 한 것이며 운영자의 평가가 아닙니다.
  • 인스타그램·틱톡은 공개 프로필로 연결되는 링크만 제공합니다. YouTube, Instagram, TikTok은 각 회사의 상표입니다. 이 사이트는 각 플랫폼과 제휴·후원 관계가 없습니다.
  • 본인 채널의 삭제·수정을 원하는 운영자는 저장소 이슈로 알려주시면 반영합니다.

라이브 중인 채널은 프사에 빨간 링과 LIVE 표시가 붙고 맨 앞으로 옵니다(10분마다 확인). 구독자 수 옆 실시간은 지금 받아온 값, "조사치"는 기사 기준 수치입니다. "영상 조회순"은 각 채널의 최근 영상 10개 안에서의 순서입니다. 아이디가 없는 채널은 위의 "채널 자동 찾기" 버튼을 눌렀을 때만 채널명으로 검색합니다(채널당 100단위, 하루 약 90개). 잘못 잡히면 카드의 ✎로 고치세요. ·
